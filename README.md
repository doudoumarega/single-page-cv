# Single-Page CV

An HTML-only CV project built while learning semantic HTML through roadmap.sh.

Project page: https://roadmap.sh/projects/single-page-cv

## Status

The HTML CV and panda favicon are included.

## Learning goals

- Structure a CV with semantic HTML.
- Organize skills, education, and work experience with appropriate headings and lists.
- Practice SEO metadata and Open Graph tags.

## View locally

1. Download this repository using **Code → Download ZIP**, then extract it, or clone it with Git.
2. Open `index.html` in a web browser such as Chrome, Edge, or Firefox.

No installation, build step, or server is required.

## Privacy

The public version uses placeholder contact details, a generic LinkedIn link, and a panda favicon instead of a personal photo.

## Scope

This project focuses on HTML structure. CSS styling will be explored separately. Social sharing previews require a publicly accessible page and cannot be tested from a local file alone.

The `og:image` tag remains a publishing TODO in the HTML.
